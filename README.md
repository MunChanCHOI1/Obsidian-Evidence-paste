# Obsidian Evidence Paste

Obsidian Evidence Paste is an Obsidian plugin that helps you paste screenshots into your notes as structured evidence entries.

## Features

- Automatically names evidence files
- Adds numbered evidence markers and callout-style descriptions
- Supports quick paste workflows for security or investigation notes
- Works as a desktop-only Obsidian plugin

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/MunChanCHOI1/Obsidian-Evidence-paste.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Build the plugin:
   ```bash
   npm run build
   ```

## Development

- Run the development build:
  ```bash
  npm run dev
  ```
- Run tests:
  ```bash
  npm test
  ```
